方法优点缺点
卫生填埋1. 处理量大，成本低；
2. 操作简便；
3. 对垃圾进行最终处置；
4. 产生的沼气可回收利用；
5. 对垃圾成分无要求。		1. 需要具备合适的地形、地质和水文条件；
2. 运行周期受自然条件的约束；
3. 对垃圾减容有限，占地面积大。
焚烧1. 能对垃圾实现最大减容处理；
2. 产生的热能可回收利用；
3. 可长期运行；
4. 占地面积小。		1. 投资和运行费用高；
2. 设备复杂，且对垃圾热值有一定的要求；
3. 操作流程复杂，需严格控制二噁英的产生；
4. 约剩下 10%的最终产物须填埋处理。
堆肥1. 运行周期不受自然条件影响；
2. 无害化和资源化程度高；
3. 有利于保护环境；
4. 投资低。		1. 垃圾可分解成分须达到 40%以上；
2. 堆肥成本高；
3. 堆肥产品受市场需求影响；
4. 约 20~25%的最终产物需填埋处理。
